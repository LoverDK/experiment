## 1. 固定权重集中不等式不能直接用于同一批结果学习的权重

**重要程度：高；影响有限样本区间与部分识别在实现上的保证。**

正文 `thm:composition` 明确写了 “fix alpha”，这是合理的限定。A.5 的
`eq:app-proof-019`（1315 行）使用

\[
E\{e^{\lambda\sum_j\alpha_j\xi_j}\mid\mathcal G\}
=\prod_j E\{e^{\lambda\alpha_j\xi_j}\mid\mathcal G\}.
\]

固定权重和条件独立保证这个步骤。正文 `eq:support-program`（358 行）却通过同一批
outcome 产生的样本方差 `vhat_j` 学习 `alphahat`。权重程序不显式读取效应均值，并不足以
证明权重与效应误差独立。在一般分布中，样本均值和样本方差可以相关。
如果把整个评价样本加入条件信息使权重固定，原来的误差均值为零和 MGF 界也未必保留。

**解析见证。** 令 100 个误差独立为 N(0,1)，每一个固定坐标都有真实 proxy 1。
置信参数 0.05 的 Chernoff 半径为 sqrt(2 log 40)=2.7162。固定坐标超界概率
0.00660；选择绝对误差最大的坐标后，超界概率

\[
1-\{2\Phi(2.7162)-1\}^{100}=0.48446.
\]

该选择规则不是 ATLAS 的实际优化器。见证证明的是“任意结果依赖权重可无条件沿用固定方向
界”这个推理不成立，不是声称固定权重定理错误或 ATLAS 的失败率等于 48.45%。

**可考虑的补足途径：** 用独立训练数据学权重并证明条件证书；在预先指定的权重族上建立
统一界；或直接推导现有优化器的数据依赖误差控制。A.8 的有限族 union bound 也需同样条件：
事后挑出几个权重，再只对已挑出的数量分配置信度，不能解决选择效应。

## 2. 样本方差与 nuisance 平均偏差不是完整的条件不确定性证书

**重要程度：高；影响 Assumption `ass:noise` 的实例化。**

`ass:noise`（270 行）要求真正的条件 sub-Gaussian MGF 上界。
`eq:aipw-estimator` 的分数样本方差除以 n 是一个方差估计量。即使它一致，也不自动成为
有限样本、所有 lambda 同时有效的 sub-Gaussian proxy。Bootstrap 稳定或经验覆盖较好不能
推出这个 MGF 性质。

**简单见证。** 两个独立 Bernoulli(1/2) 观测以 1/2 的概率完全相同。这时样本方差为零，
样本均值却偏离真实均值 1/2。零 proxy 意味着相应中心化误差几乎处处为零，与此冲突。
这说明不能普遍把经验方差视为已认证 proxy；没有否定给定真实 proxy 的定理。

A.3 的有界分数引理提供了另一条可能的路径：当有界性、共同外部训练和独立评价成立，
可用确定性的 Hoeffding 型包络。但现有分数样本方差实现与这个包络不是同一对象。

另一个需要分清的地方是 `eq:app-proof-010`（1117 行）。逐折条件偏差上界再对训练样本
取期望，可以得到

\[
|E\widehat\tau_i-\tau_i|\le E[\text{product-error bound}].
\]

它没有证明每个已经实现的训练样本下都满足同样数值的条件偏差界。一般非负随机上界 R
完全可以以 0.1 的概率等于 10、其余为 0，E R=1 无法控制每次的 R。
若 `b_i` 定义为无条件偏差，A.2 控制了它，但剩余误差在训练数据条件下均值为零还要单独证明；
若定义为条件偏差，就应给出相应条件界或高概率界。这是 A.2 向 A.5 的证书衔接问题。

**可考虑的补足途径：** 明确 b 的定义、条件 sigma-field 和失败概率分配，提供真实 proxy
或其他适配尾部的区间。不能只把 `estimated variance` 改名为 `certificate`。

## 3. CLT 中的数据依赖权重没有被现有 Lindeberg 计算自动涵盖

**重要程度：高；影响 learned composition 的渐近推断。**

A.6 的 `eq:app-proof-030`（1439 行）把权重及归一化项提出期望，
`eq:app-proof-032`（1454 行）使用独立项的方差相加。对固定权重三角阵列，两步正确。
`thm:asymptotic` 使用 “weights alpha_n” 和 “independent influence-function summands”，
但没有清晰说明权重来源。如果“independent summands”包括最终加权项，其表述可按较窄的
正确情形理解；普通未加权 influence functions 独立则不够。

**解析见证。** 8 个实验，每个有 n 个独立 N(0,1) 观测，选样本均值最大的实验，
权重为其 one-hot 向量。各原始 influence function 独立、无 nuisance 余项、方差已知。
被选估计量标准化后在每个 n 上都是 8 个标准正态的最大值，其分布函数为 Phi(x)^8。
在 x=0 处是 1/256，不是 1/2，普通 95% 区间覆盖仅约 81.67%。
这不是 ATLAS 的具体反例，但排除了仅凭原始项独立便声称任意 learned alpha CLT 的解释。

聚合余项 `sum alpha_j r_j=o_P(sqrt(V))` 已明确写在定理里；这点是有效限定。
单实验的平均 product bias rate 并不能独自推出该随机余项条件，特别是档案规模增长时。

**可考虑的补足途径：** 明确固定权重，或独立训练条件 CLT；也可以给出权重收敛到确定极限
及替换误差为 o_P(sqrt(V)) 的论证，不能省略这个步骤。

## 4. 现有区间证明是边际覆盖，不是发布后条件覆盖或全模型类一致性

**重要程度：中高；影响 “accepted composition” 与 “honest” 的解释。**

A.6 用 Slutsky 和单侧半径低估条件证明的形式是沿满足条件的序列

\[
\liminf_n P\{\tau_\star\in CI_n\}\ge1-\zeta.
\]

这不直接给出 `P(coverage | released) >= 1-zeta`，也不直接给出在整个模型类上先取
infimum 的一致覆盖。区间膨胀的三角不等式本身正确，缺少的是更强结论所需的条件。

**逻辑见证。** Z~N(0,1)，真实参数为 0，CI=[Z−z.975,Z+z.975] 边际覆盖 95%。
若只在 |Z|>z.975 时发布，发布后覆盖为零。此规则不是论文实际 release 规则，例子只说明
边际覆盖不能无条件推出选择后覆盖。可检查实际发布事件是否仅依赖适当独立训练信息，
然后证明相应条件性质。

**可考虑的补足途径：** 明确逐序列边际含义；如保留 selective/uniform 解读，需要额外的
条件推断或统一控制。新增实验的 released-target coverage 是经验诊断，不补足该逻辑环节。

## 5. 潜在机制 m 的几何界尚未自动成为表示 r 的可计算界

**重要程度：高；影响真实应用证书的可解释性。**

正文允许 m∈R^p、r∈R^q，二者可维度不同。权重程序使用 r 的距离，A.5 的 Taylor 展开
和 `eq:app-proof-107` 使用真实 m 的几何距离。后式在已经含全部真实几何的上界后
加非负 `R_hid` 是合法但可能冗余的放宽；它没有在代数上完成用 r 替代 m 的步骤。

**尺度见证。** m_source=0、m_target=1、mu(m)=m，r=0.001m 可逆，hidden residual=0。
真实效应差为 1，若把原 L=1 原样代入 r 距离，几何上界只有 0.001。即使没有信息损失，
度量的换算仍然必需。该例不反驳使用 m 距离的原定理。

当存在同一机制空间中的 lift `tilde m(r)` 时，可先明确

\[
\mu(m_\star)-\sum_j\alpha_j\mu(m_j)
=\left[\mu(\tilde m_\star)-\sum_j\alpha_j\mu(\tilde m_j)\right]
+\left[(\mu(m_\star)-\mu(\tilde m_\star))
-\sum_j\alpha_j(\mu(m_j)-\mu(\tilde m_j))\right].
\]

后一个括号才由 `ass:moderator` 控制，前一个括号应在可计算 lift 坐标上做几何展开，
并说明对应 L/H 的单位及 distortion。这个补足方向只记录在审计中，未改源稿。

## 6. Bridge 证明得到的是固定集合比较，自适应策略仍有缺口

**重要程度：高；影响 bridge 定理标题、正文解释及期望直径形式。**

`eq:app-proof-084`（2059 行）定义固定集合函数 F 的边际
Delta(u|S)=F(S∪{u})−F(S)。如果统一误差条件确实对这个边际成立，弱次模论证、
每步 2 epsilon 的优化损失，以及最终

\[
F(S_B)\ge (1-e^{-\gamma})F(S^*)-2B\epsilon/\gamma
\]

是成立的。这里比较对象 `S*` 是最优**固定集合**。这不等价于最优根据已观察 bridge
结果作后续选择的策略。算法的历史条件化边际通常也不等于这个固定 F 的无条件边际。

`eq:app-proof-103`（2357 行）把固定集合定义直接用于结果依赖的随机 S_B，
还需要说明用于评价的结果抽样与用于选择的历史之间的关系。

**期望替换的逻辑见证。** omega 为 Bernoulli(1/2)，两个候选的实现收益分别为
g(b,omega)=omega、g(c,omega)=1−omega。每个固定候选的 F 都为 1/2。
如果根据 omega 选择收益为零的候选，则 F(S(omega)) 恒为 1/2，但
E[g(S(omega),omega)]=0。因此随机集合代入 F 与真实自适应执行的期望收益不同。
这个故意选择较差候选的例子仅否定期望替换的一般恒等式，不是贪心性能反例。

**可考虑的补足途径：** 将解释限定在固定规划分布和最优固定集合；或建立以观察历史为条件的
adaptive monotonicity、adaptive diminishing returns/ratio 与适配统一估计误差的证明。
抽样规划与独立新结果评价的关系也需要明确。

新增的 retained-certificate 枚举支持限定版本的数值一致性。Operational 目标的负边际诊断
说明那批设置不满足单调前提，不是否定“若单调则成立”的条件定理。按用户要求，该 operational
诊断不进入论文。

## 7. 下界、非识别与少量边界条件

这些主要是应保留的限定，不应误报为已发现整个下界证明错误。

1. `eq:app-proof-057`（1775 行）使用截断距离。距离函数 1-Lipschitz、截断不增加常数，
   两函数在 archive hull 上同为零，目标处差为 min(L r0,M)，构造正确。距离函数可以有折角：
   K=[−1,0] 时在邻近区域是 max(x,0)，左右导数分别为 0 和 1。定理明确说
   “over the Lipschitz class”，因此该构造在指定类中合法；它没有证明同样下界在固定 H
   的 C1,1 子类里成立。
2. 两点相同档案构造证明模型类存在无法区分的情形。它不表示每一个已经观测到的非零档案，
   其 identified set 都必有同一宽度下界。若某个特定档案被额外约束大幅缩小，应重新分析。
3. A.9 令 I=sum s_j^(-2)，常数水平 ±delta 的高斯 KL 为 2 delta^2 I。
   取 delta 为小常数乘 min(M,I^(-1/2))，Pinsker 控制总变差，二点风险下界成立；
   几何不可识别项与统计项分别下界后可取最大值。这没有给出完整 radius 的匹配上界，
   也没有证明 H、hidden、优化权重等所有项具有相同 minimax 必要性。
4. 语义不充分构造要有 L>0、实际 moderator 碰撞分离量非零；若允许 L=0，所有曲面为常数，
   定理声称 c>0 就需要排除这个退化情形。常数应依赖碰撞的实际分离量，不能只用整个
   moderator 范围代替它。
5. Gaussian 下界默认非空 archive、正的 s_j^2；CLT 默认 V>0；bridge 递推使用
   0<gamma<=1 和不超过库容量的整数预算。多数是通常的非退化约定，但正式定理宜写清。
   若 F 有正边际，singleton 弱次模条件已限制 gamma<=1；F 恒零时可直接单独处理。
6. 语义定理的 “no procedure ... certify” 应理解为仅凭距离不能保证效应接近。
   永远拒绝、或给出覆盖整个效应范围的无信息区间仍然有效，并不被构造排除。

## 建议处理顺序

先处理固定权重与 learned weights、实际 proxy/bias 证书、bridge 的自适应范围，
因为三者决定主要保证是否适用于现在的算法。随后明确 m/r 几何衔接、CLT 外生性和
边际/选择后覆盖的含义。最后补齐下界模型类与非退化条件。

这些问题有一部分可通过收窄陈述或补充条件修复，有一部分需要新的推导；在这些环节完成之前，
不宜宣称“附录 A 已全部证明无误”或“实现已全面满足理论保证”。本次保留原理论，供作者决定下一步。
