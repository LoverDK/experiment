# 九类补充实验：结果与入文建议

完成日期：2026-09-07。预注册式执行协议见 `validation_v3_protocol.md`，执行差异见
`validation_v3_deviations.md`。本次只新增实验、结果和审计文件，没有修改论文、理论或 Overleaf。
全部设置的数值见 `validation_v3_tables.md` 和 `results/validation_v3/*summary.csv`；
逐目标记录、失败记录、抽样种子和运行源文件哈希保存在同一结果目录。

## 评价口径

- 合成实验中 MAE 指相对真实目标效应的平均绝对误差；区间覆盖率也可以对真实效应计算。
- NSW 和 Hillstrom 只有随机化样本得到的带噪声参考效应，报告“参考纳入率”，不能称为真实效应覆盖率。
- 以下“适合入文”包含负面结果。是否支持方法优势与是否具有论文价值是两个判断。
- 重复的 NSW 划分与重叠邻域没有产生新的独立受试者。其离散程度是设计敏感性。
- 95% 区间的经验覆盖率即使达到 100%，也不能单独证明有限样本保证；必须同时看宽度、发布率和证书前提。

## 1. 强基线的等发布率比较

每个场景 150 个独立历史校准档案、300 个独立测试档案。比较 ATLAS、完整表示最近邻、
逆方差汇总、ridge 和 RBF。使用源数据决定不确定性排序，测试真实效应仅用于评分。
发布率取 25%、50%、75%、100%。同时保留历史校准阈值的部署式评价。

50% 发布率的主要结果：

| 场景 | ATLAS MAE | Ridge MAE | RBF MAE |
| --- | ---: | ---: | ---: |
| 原设定 | 0.1355 | 0.1364 | 0.1335 |
| 中等偏移 | 0.1612 | 0.1909 | 0.1829 |
| 严重偏移 | 0.5931 | 0.3058 | 0.3654 |
| 高噪声 | 0.1596 | 0.1611 | 0.1778 |

1,000 次配对 bootstrap 在每次重采样内重新排序。中等偏移时 ridge−ATLAS 的差为
0.0297，95% 区间 [0.0048, 0.0552]；RBF−ATLAS 为 0.0218，[0.0005, 0.0500]。
严重偏移时分别为 −0.2872，[−0.3629, −0.2173] 和 −0.2277，[−0.2971, −0.1596]。
原设定与高噪声的两项比较区间都包含零。这些是逐项 Monte Carlo 比较，未作多重比较校正。
相同发布比例下各方法选择的目标可以不同，评价的是各自选择策略的风险。

**入文建议：正文简表或风险—发布率图，完整结果放附录。** 可以支持中等偏移下的选择效果；
严重偏移时强基线明显更准确，论文应保留这一限制，不能写成普遍优势。

## 2. 区间宽度、覆盖和校准迁移

本项比较含偏差项的原生高斯区间与使用独立历史带噪声目标参考进行残差校准的区间。
后者需要额外历史数据，不能当作信息条件完全相同的原生方法。

| 场景 | ATLAS 原生覆盖率 / 平均宽度 | 同场景历史校准覆盖率 / 平均宽度 |
| --- | --- | --- |
| 原设定 | 100% / 3.307 | 99.67% / 0.761 |
| 中等偏移 | 100% / 3.836 | 99.33% / 1.252 |
| 严重偏移 | 100% / 7.711 | 93.33% / 2.919 |
| 高噪声 | 100% / 3.715 | 100% / 1.518 |

只用原设定校准、直接迁移到中等和严重偏移时，ATLAS 的真实效应覆盖率下降到
90.67% 和 63.33%；RBF 分别为 87.67% 和 66.33%。历史带噪声参考的校准不等价于
真实效应校准，也不提供分布偏移下的覆盖定理。

**入文建议：正文保留宽度—覆盖权衡，校准迁移失败放附录。** 这能解释高覆盖的成本，
并说明历史校准不能替代外推条件。不要把本项的高斯 plug-in 区间称为已认证的 Chernoff 有限样本区间。

## 3. 实际拟合 nuisance、交叉拟合和弱重叠

实际生成单位级数据，实行两折交叉拟合。每个设置 200 个档案，每档案 8 个源实验，
每实验 n=100 或 400。包含已知分配概率、二次/线性 outcome 模型、拟合 logistic propensity
和错误截距 propensity。执行中的 logistic 真值为 expit(2x)，详见偏离记录。

n=400、平衡随机化时，单实验效应 RMSE：oracle 0.1000、二次拟合 0.1006、线性拟合
0.1069；对应普通 95% 区间覆盖率为 94.63%、95.19%、94.25%。
n=400、logistic 分配时，oracle、拟合 logistic、错误截距模型的 RMSE 分别为
0.1201、0.1338、0.1260，覆盖率分别为 95.56%、94.06%、91.44%。

n=100、分配概率 0.1 时，线性模型有 **170/200 个完整档案失败**，二次模型
有 **198/200 个失败**。失败由训练折处理组样本不足触发。主统计仅使用成功的完整档案；
部分完成的效应诊断另存。二次模型仅有两个成功档案，不足以支持性能判断。
在 n=400 的同一弱重叠设置中，两个拟合方法均完成 200 个档案。

**入文建议：正文给稳定设置，附录完整报告失败率。** 已经补上 oracle nuisance 之外的
实际拟合证据；小样本弱重叠的稳定性问题仍然存在。未知 propensity 情形使用的零 nuisance
偏差界是未认证的 plug-in 设置，本项不能证明它满足理论假设。

## 4. 多效应曲面和假设外压力测试

完成 5 种曲面 × 9 种设置 × 100 个档案，共 **4,500 个档案、22,500 条方法记录**。
曲面为原始、仿射、振荡、阈值与 Friedman #2；设置包括严重偏移、小样本、档案规模
4/24、高噪声、t3 汇总误差、遗漏表示坐标和更大代理误差。

基准设置下 ATLAS / RBF 的全目标 MAE：

| 曲面 | ATLAS | RBF |
| --- | ---: | ---: |
| 原始 | 0.1405 | 0.1214 |
| 仿射 | 0.0549 | 0.0592 |
| Friedman #2 | 0.1051 | 0.0997 |
| 振荡 | 0.8792 | 0.8116 |
| 阈值 | 0.5245 | 0.4717 |

振荡曲面的 ATLAS 原生区间覆盖率为 90%，低于标称 95%；此处原有平滑常数没有
在新曲面上重新认证。原始曲面遗漏 h/q 信息后，MAE 从 0.1405 上升到 0.3400；
增大代理误差后为 0.2791。阈值曲面直接违反光滑性前提。

**入文建议：附录给完整压力测试，正文选一张曲面对比表。** 证明评估不再局限于单一曲面，
同时揭示失效边界。Friedman #2 是公开回归函数在这里被用作效应曲面，不能称为公认的因果
迁移基准。t3 修改发生在汇总估计误差层，不是单位级重尾 AIPW 实验。
各方法原始 release 列的分数尺度不同；公平选择比较使用第 1 项。

## 5. 档案相关性及协方差修正

在常数和原始效应曲面上设置相关系数 0、0.3、0.7，每格 300 个档案。
三种区间使用相同点估计权重：对角方差、真实协方差、40 个独立噪声校准向量估计的协方差。

常数曲面、相关系数 0.7 时：

| 方差处理 | 覆盖率 | 平均区间宽度 |
| --- | ---: | ---: |
| 忽略相关性 | 60.67% | 0.942 |
| 真实协方差 | 96.00% | 2.035 |
| 估计协方差 | 95.00% | 2.034 |

相关系数 0.3 时，覆盖率分别为 75.67%、94.67%、94.00%。原始曲面中，完整区间的
几何项较宽，三种处理都可达到 100% 覆盖，因而另存了统计项覆盖，避免掩盖噪声失准。

**入文建议：值得放正文或紧邻主实验的附录表。** 它直接验证忽略共享信息的代价以及
协方差修正的作用。真实矩阵是 oracle 诊断，估计矩阵的结果是经验结果，不是矩阵证书定理。

## 6. NSW 分组与划分稳定性

20 次处理分层、源/目标单位完全分离的划分，邻域大小 35/50/75，最远点与随机锚点。
共 120 个预设设计，其中 **112 个满足两臂最少人数，8 个失败**。
NSW 误差及宽度单位为千美元。

| 锚点 / 邻域 | 有效设计 | ATLAS 参考 MAE | 发布率 | 参考纳入率 |
| --- | ---: | ---: | ---: | ---: |
| 最远点 / 35 | 19/20 | 2.307 | 28.95% | 80.70% |
| 最远点 / 50 | 20/20 | 1.712 | 62.50% | 85.83% |
| 最远点 / 75 | 20/20 | 1.366 | 85.83% | 90.83% |
| 随机 / 35 | 13/20 | 2.196 | 35.90% | 87.18% |
| 随机 / 50 | 20/20 | 1.714 | 55.00% | 87.50% |
| 随机 / 75 | 20/20 | 1.487 | 61.67% | 86.67% |

表内性能条件于有效设计。不同邻域对应不同参考目标、样本精度及平滑程度，MAE 随邻域
变大而下降不能单独解释为方法改进。统计不确定性仍需参考已有的单位级联合 bootstrap。

**入文建议：附录 B。** 它能回应“是否依赖某一种分组方式”，也如实说明设计敏感性。

## 7. 第二个真实随机试验：Hillstrom

64,000 名顾客中的 Men's Email 与 No Email 两臂共 42,613 人。依据处理前变量预设
24 个互斥单元，18 个有观测且全部保留，逐单元留出。所有预测、标准化与调参只用源单元。
访问率为主结局，转化率为次结局；误差单位均为**百分点**。

| 结局 | ATLAS | Ridge | RBF | 最近邻 | 逆方差汇总 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 访问率参考 MAE | 2.0364 | 1.6324 | 1.7580 | 1.8432 | 2.7929 |
| 转化率参考 MAE | 0.5293 | 0.7973 | 0.6699 | 0.6225 | 0.6242 |

原生常数 factor=1 时，ATLAS 访问率参考纳入率 77.78%、平均宽度 6.462、发布率 66.67%；
转化率分别为 94.44%、3.028、100%。访问率常数加倍后，参考纳入率升至 94.44%，
平均宽度 8.223，发布率降至 22.22%。这些常数仅作为敏感性设置，未获得新的科学认证。

源单元 LOO 的 90% 残差区间在访问率上，ATLAS 的参考纳入率 94.44%、宽度 9.440；
ridge 和 RBF 同为 94.44%，宽度分别为 8.299、8.188。每个留出任务只有 17 个残差，
95% 有限样本次序统计量秩为 ceil(18×0.95)=18，因此区间为**无限宽**，原样保存。
这个 LOO 程序不是普通 split conformal，没有宣称 conformal 有效性。

**入文建议：正文增加第二真实数据结果，构造细节与区间限制放附录。** 主结局未优于强基线，
次结局表现较好；不得只报告次结局。它仍然是一个试验内部的分组迁移，尚未提供跨独立研究的
真实实验档案，不能据此声称跨中心或跨研究有效。

## 8. Bridge 冻结规划分布下的数值稳定性

同一批 24 个档案、6 个候选、全部 64 个子集，参考抽样从 2,048 增至 8,192；
规划抽样维持 128。参考随机流有共同前缀，本项是抽样精度敏感性，不是独立复现。

保留历史证书的变体在全部 72 个“档案×预算”检查中，gamma=1，修正下界为正且不超过
贪心值。预算 1/2/3 的平均贪心值为 2.3578/2.5799/2.5801，平均最优固定集合值为
2.3578/2.5799/2.5802；平均下界为 1.4662/1.5825/1.5585。

原 operational 变体仍有负边际：中等偏移中 21.44% 的边为负，最小 −0.33079；
严重偏移中 12.85%，最小 −0.24461。两类各 12 个档案均出现负边际。
2,048 与 8,192 抽样的 operational 负号一致率 99.91%，最大边际改变量 0.00732；
保留证书变体负号一致率 100%，最大改变量 0.00749。

**入文建议：保留证书变体可用于附录的数值稳定性说明；原 operational 单调性诊断按用户要求
只在仓库留档。** 本实验没有建立自适应策略定理的前提，oracle 枚举得到的误差也不是前瞻性误差证书。

## 9. 科学常数、低报界与历史校准

原设定、严重偏移、代理误差低报三种情形，每种 300 个独立档案。
L/H/hidden 界同时乘 0.1、0.25、0.5、1、2，点估计权重保持原值，专门考察区间和发布规则。

| 场景 / 因子 | 覆盖率 | 平均宽度 | 发布率 |
| --- | ---: | ---: | ---: |
| 原设定 / 0.1 | 84.00% | 0.478 | 100% |
| 原设定 / 1 | 100% | 3.285 | 49.00% |
| 原设定 / 2 | 100% | 6.403 | 0% |
| 严重偏移 / 0.1 | 40.00% | 1.051 | 100% |
| 严重偏移 / 0.25 | 80.67% | 2.167 | 99.00% |
| 严重偏移 / 1 | 100% | 7.745 | 0.33% |
| 代理误差低报 / 0.25 | 93.00% | 1.036 | 100% |

使用第 1 项的原设定历史校准到这批新测试档案，覆盖率分别为原设定 98.67%、
严重偏移 68.67%、代理误差低报 85.67%。与第 2 项的比例略有不同，是因为这里测试档案
使用另一组预设种子；未重用第 2 项的测试记录。

**入文建议：正文简述边界，附录给完整表。** 结果说明保守程度和拒绝率依赖常数。
当前扫描是联合倍数敏感性，不能分别识别 L、H、hidden 的因果贡献，也不能从有限样本
验证真实环境中的隐藏调节界。

## 尚未被补充实验解决的问题

九个类别均已有可复现结果，但“类别已补齐”不等于所有科学问题已解决。仍缺少独立研究之间的
真实档案迁移验证、真实环境可辩护的平滑/隐藏调节证书，以及 learned weights 和自适应 bridge
相对于现有定理的完整论证。附录 A 审计给出了数学层面的具体边界。
