# Real-World Demos and Figure Scripts

Canonical examples come from `ChenLiu-1996/figures4papers`.

Useful folders include:
- `figure_ImmunoStruct`: quantitative comparison bars
- `figure_CellSpliceNet`: comparison and ablation bars
- `figure_Brainteaser`: composition breakdown bars
- `figure_VIGIL`: radar and line plots
- `figure_ophthal_review`: trend plots
- `figure_RNAGenScape`: heatmaps
- `figure_Dispersion`: geometric/concept and performance plots
- `figure_Cflows`: comparison, ablation, and trajectory plots

Browse the upstream repository when a concrete production script is needed.
