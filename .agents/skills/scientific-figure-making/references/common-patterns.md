# Common Patterns for Publication Figures

- Use wide canvases for multi-metric panels when needed to avoid crowding.
- Use a dedicated legend panel when legends would overlap data.
- Hide redundant categorical x ticks when a legend/title already identifies methods.
- Tighten y-axis ranges to the relevant range while avoiding misleading presentation.
- Use black edges and optional hatching for grayscale/print-safe separation.
- Keep semantic colors consistent: blue for proposed/key method, green for improvements, red for contrasts/baselines, neutral for references.
