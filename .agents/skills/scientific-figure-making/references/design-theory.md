# Publication Figure Design Theory

Use minimalist, high-contrast, publication-oriented matplotlib styling: sans-serif typography, top/right spines off, frameless legends, consistent line widths, and vector-friendly text.

Typical export policy is 300 DPI, with 600 DPI for dense raster bar panels when required. Prefer PDF/SVG for paper figures.

Use a stable semantic palette across panels. Multi-panel consistency is more important than per-axis embellishment. Bars should have strong edges and optional hatch channels for grayscale print. Trends should use limited line counts and uncertainty bands only when meaningful.
